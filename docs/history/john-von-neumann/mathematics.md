## Mathematical core
The mathematical core associated with John Von Neumann is set theory, operator theory, game theory, numerical analysis, automata. The point is not that every historical actor used modern notation, but that later mathematics can identify the structure of the reasoning.

- **Invariant:** something remains stable while the representation changes; invariants make verification possible.
