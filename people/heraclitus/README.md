# Heraclitus

**The Weeping Philosopher**

| | |
|---|---|
| Era | 535–475 BC |
| Origin | Ephesus, Greece |
| Field | Flux & Logos |

"No man ever steps in the same river twice." Heraclitus taught that change is the fundamental essence of the universe, governed by an underlying rational principle he called the Logos.
