# Laozi

**The Old Master**

| | |
|---|---|
| Era | 6th Century BC |
| Origin | Zhou, China |
| Field | Taoism |

Author of the Tao Te Ching, Laozi taught that the Tao (the Way) is the source of all things. Through Wu Wei—effortless action—one aligns with the natural flow of the universe.
