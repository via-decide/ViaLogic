# Martin Heidegger

**The Shepherd of Being**

| | |
|---|---|
| Era | 1889–1976 |
| Origin | Meßkirch, Germany |
| Field | Phenomenology |

Heidegger's Being and Time asked the question of Being itself, introducing Dasein and the concept of "thrownness" into existence. His work reshaped continental philosophy entirely.
