# Albert Camus

**The Absurd Hero**

| | |
|---|---|
| Era | 1913–1960 |
| Origin | Mondovi, Algeria |
| Field | Absurdism |

Camus declared life absurd but worth living. Through The Stranger, The Myth of Sisyphus, and The Plague, he showed that revolt, freedom, and passion give meaning in a meaningless universe.
