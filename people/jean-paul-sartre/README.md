# Jean-Paul Sartre

**The Champion of Freedom**

| | |
|---|---|
| Era | 1905–1980 |
| Origin | Paris, France |
| Field | Existentialism |

"Existence precedes essence." Sartre argued we are condemned to be free—there is no predetermined human nature. He declined the Nobel Prize, refusing to be institutionalized.
