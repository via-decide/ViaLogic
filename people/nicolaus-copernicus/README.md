# Nicolaus Copernicus

**The World Shaker**

- **Era:** 1473–1543
- **Origin:** Royal Prussia, Poland
- **Field:** Astronomy

With "De revolutionibus orbium coelestium", Copernicus removed the Earth from the center of the universe, triggering the Copernican Revolution and laying the foundations for modern astronomy.
