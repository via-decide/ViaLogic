# Chanakya

**The Indian Machiavelli**

| | |
|---|---|
| Era | 375–283 BC |
| Origin | Takshashila, India |
| Field | Political Science |

Chanakya authored the Arthashastra, an ancient treatise on statecraft, economic policy, and military strategy. He engineered the rise of the Maurya Empire through unmatched political cunning.
