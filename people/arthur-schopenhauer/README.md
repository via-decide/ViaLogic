# Arthur Schopenhauer

**The Philosopher of Pessimism**

| | |
|---|---|
| Era | 1788–1860 |
| Origin | Gdańsk, Poland |
| Field | Will & Representation |

Schopenhauer argued that a blind, irrational Will drives all existence, making suffering inevitable. His work influenced Nietzsche, Freud, Wittgenstein, and the philosophy of art.
