# Nāgārjuna

**The Master of Emptiness**

| | |
|---|---|
| Era | 150–250 CE |
| Origin | Andhra, India |
| Field | Madhyamaka Buddhism |

Nāgārjuna founded the Madhyamaka school of Mahayana Buddhism. His concept of Śūnyatā (emptiness) showed that all phenomena are devoid of inherent existence, revolutionizing Buddhist thought.
