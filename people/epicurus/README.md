# Epicurus

**The Philosopher of the Garden**

| | |
|---|---|
| Era | 341–270 BC |
| Origin | Samos, Greece |
| Field | Atomism & Hedonism |

Epicurus taught that pleasure—specifically tranquility and freedom from fear—is the highest good. His atomic theory anticipated modern physics, and his ethics offered a path to serenity.
