# Karl Marx

**The Revolutionary Theorist**

| | |
|---|---|
| Era | 1818–1883 |
| Origin | Trier, Germany |
| Field | Political Economy |

Marx argued that history is driven by class struggle and that capitalism contains the seeds of its own destruction. His Communist Manifesto and Das Kapital reshaped the modern world.
