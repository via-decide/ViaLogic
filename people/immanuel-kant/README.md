# Immanuel Kant

**The Clockwork Philosopher**

| | |
|---|---|
| Era | 1724–1804 |
| Origin | Königsberg, Prussia |
| Field | Critical Philosophy |

Kant never traveled more than 50 miles from home, yet revolutionized philosophy. His Categorical Imperative and Critique of Pure Reason define the boundary between what we can and cannot know.
