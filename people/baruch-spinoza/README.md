# Baruch Spinoza

**The God-Intoxicated Man**

| | |
|---|---|
| Era | 1632–1677 |
| Origin | Amsterdam, Netherlands |
| Field | Rationalism & Pantheism |

Spinoza was excommunicated for arguing that God and Nature are one substance. His Ethics, written in geometric proofs, is one of the most profound texts in Western philosophy.
